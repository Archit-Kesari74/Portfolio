# Personal Portfolio Website

A simple and professional personal portfolio website built to showcase my skills, projects, education, interests, and contact information.

## 🌐 Overview

This portfolio was created using **HTML, CSS, and Tailwind CSS** with a focus on a clean, minimal, and responsive design.

The website includes sections for:

* About Me
* Projects
* Education
* Interests & Skills
* Contact

## 🛠️ Technologies Used

* **HTML5** – Structure and content of the website
* **CSS3** – Custom styling and visual design
* **Tailwind CSS** – Utility classes for layout, spacing, responsiveness, and other common styles

## 🎨 Tailwind CSS

Tailwind CSS is used as a **utility-first CSS framework**.

Instead of writing custom CSS for every element, predefined utility classes can be added directly to HTML elements.

For example:

```html
<div class="flex items-center justify-between">
```

Here:

* `flex` enables Flexbox
* `items-center` vertically centers the items
* `justify-between` distributes the items with space between them

Tailwind is mainly used in this project for common layout and spacing utilities, while custom CSS is used for specific design requirements.

## 🚀 How to Run

1. Clone the repository:

```bash

```

2. Open the project folder.

3. Open `index.html` in a web browser.

No additional installation or build process is required because Tailwind CSS is loaded using its CDN.
